# Tier 0 · Absolute Foundations (`neg04` – `neg00`)

Start here if you are new to C or transitioning from a high-level managed language (Python, JavaScript, Java, Go). These five modules establish a rock-solid foundation before entering hardware memory models and manual pointer arithmetic in Tier 1.

<div class="grid cards" markdown>

- **neg04 · Dev Environment & First Program**

    Install GCC/Clang, configure `clangd` and `clang-format`, decode every token of `hello.c`, and run your first GDB session.

    [:octicons-arrow-right-24: Start Module neg04](neg04-dev-environment.md)

- **neg03 · Variables, Types & Operators**

    Primitive data types, two's complement representation, arithmetic/bitwise operators, `printf`/`scanf`, and explicit type casting.

    [:octicons-arrow-right-24: Open Module neg03](neg03-variables-types-operators.md)

- **neg02 · Control Flow & Loops**

    Branching (`if`/`else`), `switch` jump tables, `for`/`while`/`do-while` loops, loop invariants, and CPU branch prediction basics.

    [:octicons-arrow-right-24: Open Module neg02](neg02-control-flow-loops.md)

- **neg01 · Functions, Scope & Recursion**

    Function anatomy, pass-by-value semantics, block/file scope, `static`/`extern`, call-stack recursion, and `argc`/`argv`.

    [:octicons-arrow-right-24: Open Module neg01](neg01-functions-scope-recursion.md)

- **neg00 · Arrays, Strings & Struct Basics**

    Contiguous 1D/2D arrays, null-terminated C strings, `struct` aggregation, `typedef` aliases, and `enum` definitions.

    [:octicons-arrow-right-24: Open Module neg00](neg00-arrays-strings-structs.md)

</div>
